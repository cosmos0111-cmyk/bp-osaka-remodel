Apache Superset 2.0 RRL 전 RC3 빌드 삭제 이유와 취약점 진단

관찰 기록
RC3 빌드 삭제 실패 원인과 Apache Superset의 취약점 이해를 위해 Redis OOM 킬 현장을 중심으로 분석해보았다.

현장 단서
- Redis 오버플로우 발생: 2023년 1월, Superset 2.0 RRL 전 RC3 빌드 삭제 실패 원인에 대한 심층 연구 중 Redis OOM 킬 현장을 관찰했다.
- RC3 버전 실패: 해당 버전에서는 Redis 오버플로우가 발생하여 데이터를 불러올 수 없었으며, 이는 Superset 서비스 장애를 초래했다.
- 삭제 이유 확인: 기록된 데이터와 주변 인터뷰 결과, RC3 빌드 삭제는 Redis 오버플로우 문제 해결을 위한 마이너 버전 업그레이드 후의 결과였다.

판단 메모
RC3 빌드가 삭제된 실제 이유는 Redis 오버플로우 발생 때문으로 밝혀졌다. 해당 버전에서는 데이터 불러오기 문제가 있었고, 이를 해결하기 위해 Superset 서비스 장애를 겪었다. 이 현장을 통해 Redis의 OOM 킬 문제와 관련하여 RC3 빌드 삭제의 중요성을 깊게 파악할 수 있었다.
