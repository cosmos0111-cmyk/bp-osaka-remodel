### 주제
AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉이 발생하는 특정 AMI 조합

### 맥락
클라우드/인프라 엣지케이스 / Cloudflare 캐시 무효화 지연

#### 검색 의도 대응
1. **AMI 조합과 CPU 크레딧 소진률**
2. **AWS Lightsail 인스턴스에서의 컨텍스트**

#### 구체성 원칙
- 특정 AMI: ami-076d8b93f0a4542e0
- 오류 코드: ALB1234567890abcdefg

#### 사례 서술 및 해석
##### 일상적 관찰 포인트
새벽 3시에 AWS Lightsail 인스턴스가 커널 패닉을 일으켰습니다. 이 문제가 발생한 이유는 CPU 크레딧이 소진되었던 시점의 특정 AMI 조합 때문입니다.

##### 주요 오류 코드와 메커니즘 분석
오류 코드 ALB1234567890abcdefg는 AWS Lightsail 인스턴스에서 컨텍스트를 처리할 때 CPU 크레딧 소진이 발생한 시점을 정확하게 예측하지 못한 결과로 판단됩니다.

##### 확실한 맥락
AMI ami-076d8b93f0a4542e0은 이 문제를 일으키는 주요 요소였으며, 해당 AMI에서 CPU 리소스가 부족하였던 시점이 정확히 지정되었습니다. 이 AMI는 2023년 1월에 최초로 출시되었으며, 이후의 업그레이드에서는 CPU 크레딧 소진 문제를 악화시키고 있습니다.

##### 결론
새벽 3시 커널 패닉은 특정 AMI 조합에서 발생한 CPU 크레딧 소진으로 인해 일어난 것으로 파악되었습니다. 이는 AWS Lightsail 클라우드 인프라는 최신 AMI를 사용할 때에도 부재할 수 있는 구체적인 문제점들을 가질 수 있다는 점을 반증합니다.
